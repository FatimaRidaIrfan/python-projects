## 1. Beginner Projects

These projects helped me practise Python fundamentals.

### 1. Simple Calculator
A command-line calculator that performs mathematical operations.

**Features:**
- Addition, subtraction, multiplication and division
- Exponentiation and modulus
- Handles division by zero
- Handles invalid operations

### 2. User Account Management System
A command-line program for managing user records and roles.

**Features:**
- Register users
- View and search users
- Update user roles
- Delete user records

### 3. Personal Expense Tracker
A command-line application for recording and managing personal expenses.

**Features:**
- Add expenses with names, amounts and categories
- View all expenses
- Calculate total expenses
- Search expenses by category
- Delete expenses

### 4. Password Generator
A command-line application that generates random passwords using Python's `secrets` and `string` modules.

**Features:**
- Generate passwords of a chosen length
- Include uppercase and lowercase letters
- Include numbers and special characters
- Validate user input
- Generate multiple passwords
