# Python Projects

Welcome to my Python Projects repository!

This repository documents my Python programming journey through practical projects. It includes beginner and intermediate projects that help me apply concepts, improve my problem-solving skills, and gain hands-on experience.

## 1. Beginner Projects

These projects helped me practise Python fundamentals.

### 1. Simple Calculator

A command-line calculator that performs mathematical operations.

**Features:**
- Addition, subtraction, multiplication and division
- Exponentiation and modulus
- Handles division by zero
- Handles invalid operations

### 2. User Account Management System

A command-line program for managing user records and roles.

**Features:**
- Register users
- View and search users
- Update user roles
- Delete user records

### 3. Personal Expense Tracker

A command-line application for recording and managing personal expenses.

**Features:**
- Add expenses with names, amounts and categories
- View all expenses
- Calculate total expenses
- Search expenses by category
- Delete expenses

### 4. Password Generator

A command-line application that generates random passwords using Python's `secrets` and `string` modules.

**Features:**
- Generate passwords of a chosen length
- Include uppercase and lowercase letters
- Include numbers and special characters
- Validate user input
- Generate multiple passwords

## 2. Intermediate Projects

These projects helped me explore additional Python concepts and develop practical programming skills.

### 1. File Management System

A command-line application for performing basic file and folder management operations.

**Features:**
- View files and folders
- Create folders
- Create text files
- Rename files
- Delete files
- Delete empty folders

### 2. Log File Analyzer

A Python program that reads a log file and counts different types of log messages.

**Features:**
- Read log files
- Identify INFO, WARNING and ERROR messages
- Count each type of log message
- Display a summary of log entries

### 3. File Integrity Checker

A Python program that uses SHA-256 hashing to detect changes in file contents.

**Features:**
- Read file contents
- Generate SHA-256 hashes using `hashlib`
- Compare original and new file hashes
- Detect file modifications

### 4. Basic Network Scanner

A Python program that checks TCP port connectivity using the `socket` module.

**Features:**
- Scan specified IP addresses
- Check multiple TCP ports
- Handle connection-refused errors
- Handle connection timeouts
- Close sockets using `finally`

### 5. System Information Collector

A Python program that collects and displays basic system information using built-in Python modules.

**Features:**
- Retrieve hostname
- Display Python version
- Identify the current username
- Retrieve operating system information
- Display OS release
- Identify machine architecture
- Retrieve processor information
